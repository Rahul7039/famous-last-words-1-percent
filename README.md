The funniest one-line farewell a phone could say as its battery hits 1 percent — one line, judged blind, pairwise, by a stand-up-comic judge model.

> I held 1 percent for 40 minutes just to watch you panic. Worth it. Goodbye.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (and prints it).
